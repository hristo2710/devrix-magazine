# DevriX Magazine

A custom responsive WordPress magazine theme developed for the DevriX Front End Challenge.

## Features

- Custom WordPress theme built with PHP, CSS and JavaScript
- Custom article post type and categories
- Featured and Breaking News sections
- Interactive Featured News section
- Live article search using the WordPress REST API
- Responsive navigation
- Individual article pages
- Editable content through the WordPress admin panel

## Technologies

- WordPress
- PHP
- HTML5
- CSS3
- JavaScript

## Installation

1. Install WordPress locally.
2. Copy the `devrix-magazine` folder into `wp-content/themes/`.
3. Activate the theme under Appearance > Themes.
4. Import the supplied demo content, if available.
5. Configure the website's navigation menu.

## Demo Content

The `demo-content` directory contains images used in the demo website.

Images may need to be uploaded to the WordPress Media Library and assigned to their corresponding articles.
